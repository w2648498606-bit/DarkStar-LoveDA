# LoveDA 七类遥感语义分割

这是一次围绕 LoveDA 数据集开展的遥感语义分割学习与实验记录。项目关注城市与乡村场景中的七类地物分割，通过连续实验比较模型结构、训练策略、类别表现和跨场景泛化。

## 项目结果

| 评测 | 实验 | mIoU |
|---|---|---:|
| 独立验证集 | E090 | **0.545243** |
| Hidden Test | E090 单模型直接预测 | **0.525061** |

E090 的独立验证最佳结果出现在第 5 个 epoch。

## 最终方案

- MiT-B2 编码器
- UPerNet 风格解码器
- 多尺度训练
- 稀有类别采样
- 轻量类别感知训练策略
- 单模型直接预测

最终训练配置记录在 [`train_e090.py`](train_e090.py)，预测流程记录在 [`predict_e090_lite_direct_test.py`](predict_e090_lite_direct_test.py)。

## 实验演进

| 阶段 | 代表实验 | 独立验证 mIoU | 主要内容 |
|---|---|---:|---|
| 基线建立 | E007 | 0.514223 | 完成 MiT-B2 分割基线与训练流程 |
| 架构筛选 | E009 | 0.524680 | 确定 MiT-B2 与 UPerNet 风格解码器的组合 |
| 训练策略组合 | E035 | 0.530609 | 引入多尺度训练与稀有类别采样 |
| 损失与采样优化 | E037 | 0.536149 | 继续改善类别不均衡下的训练表现 |
| 跨尺度上下文实验 | E042 | 0.545099 | 加强不同尺度目标与场景信息的利用 |
| 最终轻量优化 | E090 | **0.545243** | 形成最终类别感知训练方案 |

整个过程形成了 **74 个实验目录索引**和 **70 份训练 history 记录**。实验中同时记录整体 mIoU、分类别 IoU、Urban/Rural 分域表现以及训练曲线，用于比较方案和定位误差。

## 学习过程中的主要认识

1. 模型结构是第一阶段最明显的影响因素。E009 相比 E007 的独立验证 mIoU 提高了 0.010457。
2. 多尺度训练与稀有类别采样组合后，E035 的独立验证 mIoU 达到 0.530609。
3. 后续实验的重点从更换主体架构转向类别不均衡、跨尺度信息和城乡场景差异。
4. 最终方案 E090 的独立验证 mIoU 相比 E007 提高了 0.031020，并在 Hidden Test 上取得 0.525061。
5. 单一总分不足以解释模型表现，分类别结果、分域结果和失败实验同样参与了方案判断。
